# Article library

Markdown snapshots of Deshitification's WordPress articles. WordPress remains the publishing source of truth; front matter records the WordPress post ID, status and canonical URL at export time.

## Sections
- `educational/`: evergreen practical guides and explainers.
- `current-affairs/YYYY/`: time-sensitive news and analysis, grouped by year.
- `templates/`: reusable article structure.

## Editorial conventions
- Target 450–600 words; exceed 700 only when genuinely justified.
- Use short paragraphs, concise headings and one primary visual where useful.
- Prefer primary sources; distinguish verified facts, estimates and examples.
- Use fictional/synthetic examples only. Never include employer, client, supplier or customer data.
- A Git commit does not publish a WordPress post. Publishing status is controlled in WordPress.

## Naming
Use each WordPress post's lowercase kebab-case slug. Keep one article per Markdown file. Store original visual assets in the matching topic folder under `diagrams/`.
