# Safe Demonstration Guidelines

This repository is public-portfolio material.

- Use fictional names, references, timestamps and values.
- Never commit employer, client, supplier, colleague or customer information.
- Never commit API keys, passwords, access tokens, private URLs or configuration files.
- Do not copy proprietary workflows, screenshots, code or documents.
- Keep demonstrations offline and read-only unless a separate test environment is explicitly documented.
- Clearly label assumptions, limitations and synthetic data.
